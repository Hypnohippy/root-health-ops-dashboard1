## Phase 1B whole-conversation coaching repair — pending human acceptance
The cautious-Alex rehearsal exposed sparse useful prompts and a missed close. Historical raw model output was not retained, so the specific suppression cause for each remembered candidate cannot be reconstructed. The repair keeps a bounded in-memory conversation hint set: up to seven exact excerpts for time constraint, exploratory intent, budget/timeframe uncertainty, problem language, follow-up requirements and contact boundary, plus eight recent question excerpts. No speaker labels or inferred diagnoses are stored. The server combines these hints with the bounded current transcript; exact live advice still must cite a current non-gap source excerpt. The model is instructed to revise a cautious, provisional stance and explicitly state a current realistic call goal, then give actual words for the next move. A missing goal is rejected with `missing_call_goal` rather than silently shown.

Opportunity checks now recognise the observed time-poor wording, repeated timing/budget routes, follow-up content, brief-summary/closing language, a possible pause after a non-progressing answer, and possible overlong explanation after a stall. These are text heuristics only: neutral transcription does not establish who spoke, whether David paused, or who produced a long turn. Follow-up content raises a review/next-step route; it does not claim agreement. An accepted brief plus closing language raises an unresolved-close opportunity unless a future turn provides a clear refusal or a sufficient next state. The model must select the goal (sale only if readiness supports it; otherwise second meeting, defined review point or graceful exit); this is not a deterministic sales classification.

Suggestion cards display the model's short current goal separately from the lead and exact quote. Diagnostics distinguish generated, suppressed, queued, selected, render-attempted, visible and visibility-ended events, with per-visible-interval duration. The visible count is the count of suggestions that crossed the 50% viewport threshold, not proof of attention. Same evidence can support a different route when its angle/wording is genuinely new; existing duplicate and exact grounding checks remain.
